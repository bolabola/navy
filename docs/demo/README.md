# 搭建公开演示站

`navy-demo.json` 是一套示例书签：英文的 **Start** 页和 **中文** 页，覆盖列表、图标网格、详情、分组和空看板几种状态。用它单独部署一个演示站，访客以只读方式浏览，不会动到你自己的数据。

## 步骤

1. **部署一个单独的 Worker**（名字和你自己用的站点区分开）：

   ```bash
   npm install
   npm run deploy -- --name navy-demo
   ```

   首次部署会提示设置管理员密码。演示站的密码请用一个**和自己站点不同**的随机长密码。

2. **导入示例数据**：打开 `https://navy-demo.<你的子域名>.workers.dev`，点右上角“登录”，然后在顶栏的**数据**菜单里选“导入完整 JSON”，选择本目录下的 `navy-demo.json`。

3. **退出登录**，用无痕窗口打开一遍，确认访客看到的是 Start 页。

4. **把链接放进 README**：在中英文 README 顶部的按钮旁边加上“在线演示 / Live demo”链接。

## 注意

- 演示站对所有人只读：访客可以搜索、切换显示方式、折叠看板，这些只保存在访客自己的浏览器里，不会改变演示数据。
- 不要在演示站上配置云盘备份，也不要放任何私人链接。
- 以后想更新示例内容，修改 `navy-demo.json` 后重新导入即可。测试里会校验这个文件，格式不对时 CI 会报错。
